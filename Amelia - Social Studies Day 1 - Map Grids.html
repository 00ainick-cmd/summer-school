Finding Places with a Grid

Maps use a grid of letters and numbers to name an exact spot. The letter names the column, the number names the row. Together they give an absolute location, like C2.

What this lesson teachesDescribe and use absolute location using a grid system.
01

How a grid works

Read the column letter first, then the row number. The letter and number together name one square.

  • Columns are labeled with letters: A, B, C, D.
  • Rows are labeled with numbers: 1, 2, 3, 4.
  • A square like B3 means column B, row 3.
02

Find it on the map

Read the place, then tap the square it sits in.

03

Watch out for this

Common mix-up
Writing the number before the letter, like 3B.
Read the column letter first, then the row number. The square is B3, not 3B. Letter, then number.
