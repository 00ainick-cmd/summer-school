Session 02

Rational vs Irrational

Every real number falls into one of two camps. Today you build a sharp test for which is which, then sort a stack of suspects without flinching.

What this session teachesKnow the differences between rational and irrational numbers.
01 / LEARN

The test in one question

A real number is rational if it can be written as a fraction p/q where p and q are integers and q is not zero. If no such fraction exists, the number is irrational.

Rational

Includes integers, terminating decimals, and repeating decimals. All of these can be rewritten as p/q.

7 = 7/1 · 0.25 = 1/4 · 0.333... = 1/3 · √25 = 5

Irrational

Decimal runs forever with no repeating block. Cannot be written as p/q.

√2 = 1.41421... · pi = 3.14159... · e = 2.71828... · 0.101001000...
Engineering check. Square roots are the common trap. If the number under the root is a perfect square (1, 4, 9, 16, 25, 36, 49, 64, 81, 100), the root is a whole number and rational. Anything else under a square root is irrational.
02 / LEARN

Why a fraction always behaves

If a number is p/q, long-division has only finitely many possible remainders less than q. Eventually a remainder repeats, which forces the decimal to repeat (or stop). That guarantee fails for numbers like √2: no fraction can land it, so its decimal never settles into a pattern.

The constructed decimal 0.101001000100001... looks tame, but the gaps grow forever. No fixed block ever repeats, so no fraction can name it. Irrational.
