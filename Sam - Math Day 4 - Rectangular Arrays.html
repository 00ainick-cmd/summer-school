Day 4

Rectangular arrays

When you line up dots in even rows and columns, you make an array. You can find the total fast by adding the rows.

By the end, you can count an array and write a row-sum equation for the total.

What this lesson teaches Find the total number of objects arranged in a rectangular array with up to 5 rows and 5 columns, and write an equation to represent the total as a sum of equal addends.
01

Rows and columns

An array is dots in even rows and columns. Like a tile floor or a tray of muffins.

Row. A line that goes side to side.

Column. A line that goes up and down.

In an array, every row has the same number of dots. Every column has the same number too.

Same in every row. That is what makes it an array.
02

2 rows of 3

Here is an array with 2 rows. Each row has 3 dots. Count them all.

3 + 3 = 6
Row 1 is 3. Row 2 is 3. Total is 6.
03

4 rows of 5

A bigger array. 4 rows. Each row has 5 dots.

5 + 5 + 5 + 5 = 20
4 rows, each with 5 dots. Total is 20.
04

Read the row, write the sum

Here is the rule for writing the equation:

Step 1. Count the dots in one row.

Step 2. Add that number once for every row.

3 rows of 2 is 2 + 2 + 2 = 6.
5 rows of 3 is 3 + 3 + 3 + 3 + 3 = 15.
2 rows of 4 is 4 + 4 = 8.

05

Try one

An array has 3 rows. Each row has 2 dots. What equation shows the total?

Each row has 2 dots, and there are 3 rows. So you add 2 three times: 2 + 2 + 2 = 6.
